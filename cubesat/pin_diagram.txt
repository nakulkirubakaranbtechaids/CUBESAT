--------------------------------------------------------------------------------
1.1 I2C SENSOR BUS WIRING (Shared 2-Wire Bus)
--------------------------------------------------------------------------------
The MPU-6050, BMP-280, and MLX-90614 all connect in parallel to the same I2C pins:

  SENSOR PIN      -->   ESP32 PIN           NOTES
  --------------------------------------------------------------------------
  VCC (All 3)     -->   3.3V (or VIN/5V)    Power line (3.3V recommended)
  GND (All 3)     -->   GND                 Common ground
  SCL (All 3)     -->   GPIO 22             I2C Clock line
  SDA (All 3)     -->   GPIO 21             I2C Data line

  I2C Addresses:
    - MPU-6050 (IMU):          0x68 (AD0 -> GND)
    - BMP-280  (Barometer):    0x76 or 0x77 (SDO -> GND/VCC)
    - MLX-90614 (IR Temp):     0x5A


--------------------------------------------------------------------------------
1.2 LoRa SX1278 (433MHz) SPI TRANSCEIVER WIRING
--------------------------------------------------------------------------------
  LoRa SX1278 PIN -->   ESP32 PIN           NOTES
  --------------------------------------------------------------------------
  VCC             -->   3.3V                *** CRITICAL: DO NOT USE 5V! ***
  GND             -->   GND                 Ground
  SCK             -->   GPIO 18             SPI Clock (VSPI SCK)
  MISO            -->   GPIO 19             SPI MISO  (VSPI MISO)
  MOSI            -->   GPIO 23             SPI MOSI  (VSPI MOSI)
  NSS / CS / SS   -->   GPIO 5              Chip Select
  RST / RESET     -->   GPIO 14             Module Reset
  DIO0            -->   GPIO 26             Packet Rx/Tx Interrupt
  ANT             -->   433MHz Antenna      Monopole / Helical Antenna


--------------------------------------------------------------------------------
1.3 NEO-6M GPS MODULE (Hardware Serial2 UART)
--------------------------------------------------------------------------------
  NEO-6M GPS PIN  -->   ESP32 PIN           NOTES
  --------------------------------------------------------------------------
  VCC             -->   3.3V or 5V          Power
  GND             -->   GND                 Ground
  TX              -->   GPIO 16 (RX2)       GPS Transmit -> ESP32 Receive
  RX              -->   GPIO 17 (TX2)       GPS Receive  <- ESP32 Transmit


--------------------------------------------------------------------------------
1.4 ANALOG IR SPECTROMETER (Photodiode / Phototransistor Sensor)
--------------------------------------------------------------------------------
  SENSOR PIN      -->   ESP32 PIN           NOTES
  --------------------------------------------------------------------------
  VCC             -->   3.3V                Power
  GND             -->   GND                 Ground
  SIGNAL / OUT    -->   GPIO 34 (ADC1_CH6)  Input-only Analog Pin (12-bit ADC)

--------------------------------------------------------------------------------
2.1 LoRa SX1278 RECEIVER WIRING
--------------------------------------------------------------------------------
  LoRa SX1278 PIN -->   ESP32 PIN           NOTES
  --------------------------------------------------------------------------
  VCC             -->   3.3V                *** CRITICAL: DO NOT USE 5V! ***
 Ground
  SCK             -->   GPIO 18             SPI Clock
  MISO            -->   GPIO 19             SPI MISO
  MOSI            -->   GPIO 23             SPI MOSI
  NSS / CS / SS   -->   GPIO 5              Chip Select
  RST / RESET     -->   GPIO 14             Module Reset
  DIO0            -->   GPIO 26             Packet Interrupt
  ANT             -->   433MHz Antenna      Antenna for RF reception


--------------------------------------------------------------------------------
2.2 PC CONNECTION & DUAL-LINK OUTPUT
--------------------------------------------------------------------------------
  - USB Serial: Connect ESP32 Micro-USB port to PC (COM port at 115200 baud).
  - WiFi Dual-Link: ESP32 automatically broadcasts UDP telemetry packets on
    Port 8888 (Connects to router SSID or starts "CubeSat-GS-WiFi" hotspot).

PART 3: COMPLETE ESP32 PINOUT REFERENCE TABLE
================================================================================

  GPIO PIN    FUNCTION               CONNECTED COMPONENT
  --------------------------------------------------------------------------
  GPIO 5      VSPI SS / NSS          LoRa SX1278 (Chip Select)
  GPIO 14     GPIO OUTPUT            LoRa SX1278 (RST / Reset)
  GPIO 16     UART2 RX (RX2)         NEO-6M GPS (TX Pin)
  GPIO 17     UART2 TX (TX2)         NEO-6M GPS (RX Pin)
  GPIO 18     VSPI SCK               LoRa SX1278 (SCK Clock)
  GPIO 19     VSPI MISO              LoRa SX1278 (MISO Data)
  GPIO 21     I2C SDA                MPU-6050, BMP-280, MLX-90614 (SDA)
  GPIO 22     I2C SCL                MPU-6050, BMP-280, MLX-90614 (SCL)
  GPIO 23     VSPI MOSI              LoRa SX1278 (MOSI Data)
  GPIO 26     GPIO INPUT             LoRa SX1278 (DIO0 Interrupt)
  GPIO 34     ADC1 Channel 6         Analog IR Spectrometer (Analog OUT)
  3.3V        3.3V Output Power      LoRa, MPU6050, BMP280, MLX90614, IR Spec
  GND         Power Ground           Common Ground for ALL components
